기존 코딩 테스트 화면처럼 문제 설명·코드 에디터·실행 결과를 한 화면에 두고, 같은 계열의 Java·Python 환경에서 코드를 실행하는 웹 IDE입니다.
누구나 문제를 둘러볼 수 있고, Google 계정으로 가입하면 코드를 작성·실행·채점하고 풀이 기록을 남길 수 있습니다.

주요 특징:

* **solution 함수형**: `class Solution { ... solution(...) }` / `def solution(...)`을 테스트 케이스마다 호출하고 반환값을 기댓값과 타입까지 비교. `[1, 2]`, `"abc"`, `[["a", 1]]`처럼 기존 표기 그대로 입력.
* **표준 입출력형**: PCCE·입출력 문제처럼 `main`/스크립트를 입력과 함께 실행하고 출력 비교.
* **코드 실행 / 제출 후 채점**: 코드 실행은 보이는 케이스로 입력·기댓값·출력까지, 제출은 히든 케이스로 통과/실패·시간·메모리와 점수만 보여 준다(기존와 같음).
* **공용 문제집·컬렉션**: 문제·채점 케이스·컬렉션은 모두가 같이 본다. 편집 권한이 있는 사용자만 바꾸고, 바꾸면 모두에게 적용된다. 컬렉션 이름의 `/`는 계층이다(예: `모의고사/1회`, Vaultwarden처럼). 첫 화면에 컬렉션을 카드로 보여 주고, 상위 묶음을 열면 하위 컬렉션의 문제를 모아 보여 준다.
* **내 풀이 기록·폴더**: 작성 코드·내 테스트 케이스·메모·풀이 시간·채점 결과와 폴더(문제를 내 방식대로 나누는 개인 정리)는 계정마다 따로 저장된다. 처음에는 기본 폴더 구성으로 시작한다.
* **자동 저장**: 코드·내 케이스·메모를 기기에 먼저 보관하고, 입력이 5초 멈추거나 계속 입력한 지 30초가 되면 변경분만 서버에 동기화. 새로고침·통신 실패 후에도 같은 계정의 임시 저장본을 복원.
* **격리 실행**: 사용자 코드는 인터넷이 차단된 runner 컨테이너에서 권한을 낮춘 uid로 실행.
* **Google 로그인**: 로그인과 회원가입 모두 Google 계정. 처음이면 약관 동의(만 14세 이상·이용약관·개인정보 수집·이용) 화면을 거친다.
* **관리자 모드**(`/admin`): 마스터 비밀번호로만 연다. 사용자 목록·상세 현황을 보고, 편집 권한을 주거나 회수하고, 신규 가입 전체 허용·중지와 사용자 삭제를 관리한다.
* **휴대폰·태블릿**: 아이폰·갤럭시·아이패드에서도 모든 기능을 쓸 수 있다. 휴대폰에서는 문제 화면을 문제·코드·결과 탭으로 나누고 실행·제출 버튼을 화면 아래에 둔다. 코드를 쓰는 동안(키보드가 열린 동안)은 탭·버튼을 모두 숨겨 화면 전체에 코드를 보여 주고, 긴 줄은 들여쓰기에 맞춰 줄바꿈하며, 오른쪽 손잡이로 긴 코드를 빠르게 오가고 두 손가락으로 글자 크기를 바꾼다. 태블릿(가로 768px 이상)은 데스크톱처럼 좌우로 나눠 보여 준다.
* **실행 환경**: Java(OpenJDK 21.0.2), Python 3.13.13.
