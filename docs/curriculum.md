## 콘텐츠 편집

전체 제목에서 과거 일련번호와 레벨 표기를 제거하고 단계·유형을 표시한다. 본문에는 학습 위치·함수형 풀이 계약·시간 제한·클리어 기준을 넣고 기존 문제 설명·제약·예제의 의미를 유지한다. 그림 URL은 Markdown 이미지로 표시한다. 기존 기업명과 대상 연습 플랫폼 언급을 제거한다.

명시 수정: 직각삼각형 탈출 문제의 높이·반환값 설명, 영역 인구 합 문제의 인구 배열 설명, 도미노 28종의 텍스트 정의를 보완한다. 문제 ID·함수 매개변수·반환 타입·시작 코드·보이는 예제·숨은 테스트셋과 사용자별 풀이 기록은 변경하지 않는다. 기존 컬렉션 12개는 ID를 보존하여 새 학습 단계와 실전 모의고사로 재편한다.

## 반영 절차

1. 익명 공개 API의 문제·기본 폴더·컬렉션만 읽어 catalog JSON을 준비한다.
2. `node scripts/curriculum.mjs plan <catalog.json> <plan.json> <report.md>`로 편집안을 생성한다.
3. 편집안과 검사 결과를 검토한 뒤 운영 컨테이너에서 `node scripts/curriculum.mjs apply <database> <plan.json> <backup-dir>`를 실행한다.
4. 스크립트는 적용 직전 제목·본문·컬렉션이 계획 생성 시점과 같은지 확인하고, 공용 편집 필드만 백업한 뒤 한 트랜잭션으로 반영한다. 예상 밖 문제·개인 컬렉션·이름 충돌이 있으면 반영하지 않는다. 동일 계획의 재실행은 멱등이다.
5. 공개 API로 전체 문제 수, 세트별 배정, 제외 명칭 잔존 여부와 채점 계약 보존을 재확인한다.
