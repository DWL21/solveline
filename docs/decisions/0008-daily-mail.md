# 0008. 일일 메일을 Worker cron과 Resend로 보낸다

## 결정
- 평일 아침 새 문제 한 개를 메일로 보낸다. 모든 구독자가 같은 날 같은 회차를 받는다.
- cron은 Pages에 두지 않고 별도 Worker(`apps/mailer`)에 둔다. 데이터는 같은 D1을 쓴다.
- 발송은 Resend 무료 플랜으로 시작한다. 하루 100통 한도에서 인증 메일·재시도 몫을 뺀 90명을 구독 상한으로 둔다.
- 구독자가 늘면 Cloudflare Email로 옮긴다. 서비스별 코드는 `apps/api/src/mail-sender.ts`에만 둔다.
- pahidc에서 직접 보내지 않는다. 발신 IP가 공개되고, 사용자 데이터를 두지 않는 원칙(0007)과 충돌한다.

## 동작
- `RESEND_API_KEY`와 `DAILY_FROM`이 없으면 구독과 발송이 모두 꺼진다.
- 구독은 이메일 인증을 거친다. 메일 보안 검사가 링크를 미리 열어도 처리되지 않게 인증·수신거부는 버튼(POST)으로 한다.
- 발송 기록의 기본 키(회차, 구독자)와 Idempotency-Key로 중복 발송을 막는다. 무료 CPU 한도에 맞춰 5분마다 30통씩 보낸다.
- 영구 반송·스팸 신고는 웹훅으로 받아 구독을 멈추고, 다시 신청해도 보내지 않는다.

## D1 마이그레이션
`0001_schema.sql`은 운영에 이미 적용했으므로 다시 만들지 않는다. 그 뒤의 표는 다음 번호 파일로 더하고, `db-node.ts`와 같은지 테스트로 확인한다.
