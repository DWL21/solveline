# 0005. 폴더는 사용자별, 컬렉션은 공용

- 상태: 채택 (2026-10-26)
- 바꾼 것: [0004](0004-google-login-and-roles.md)의 "폴더 공용·컬렉션 사용자별"

## 결정

- **폴더**: 사용자마다 따로 만드는 개인 정리. 사용자·문제마다 폴더 하나(`folder_items`). 비회원은 기본 폴더를 본다.
  - 기존 공용 폴더는 **틀**(`folders.user_id IS NULL`, 문제 배치는 `problems.folder_id`)로 남기고, 기존 사용자와 이후 가입자에게 개인 폴더로 복사한다. 복사한 뒤에는 각자 이름·구성을 바꿔도 서로 영향이 없다.
- **컬렉션**: 모두가 같이 보는 공용 묶음. 편집 권한자만 만들고 바꾼다. 기존 사용자별 컬렉션은 모두 공용으로 옮겼다(운영자 예전 데이터 넘겨받기에서 컬렉션은 뺐다).
  - 이름의 `/`는 계층이다(Vaultwarden 방식). `모의고사/1회`는 `모의고사` 아래. 상위 단계는 실제 컬렉션이 없어도 묶음으로 보이고(`#/cg/<경로>`), 열면 하위 컬렉션의 문제를 모아 보여 준다. 이름은 앞뒤·구분자 주변 공백을 정리하고 같은 이름은 막는다.
- 첫 화면은 최상위 컬렉션을 카드(문제 수·하위 수·맞힌 비율)로 보여 주고, 컬렉션 안에서는 하위 컬렉션 카드와 경로(이동 경로)를 보여 준다.
